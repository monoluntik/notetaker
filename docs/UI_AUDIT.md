## Найденные проблемы

### P0 — функциональность и надёжность
1. **Тихая перезапись при одновременном редактировании** возможна в обход проверки версии:
   перетаскивание в календаре, переключатель «активна» в списке, корзина
   (удалить/восстановить/удалить навсегда), удаление и сброс отдельного вхождения не передают
   и не проверяют версию; версия в API необязательна.
2. **Исчерпание последовательности `reminder_deliveries.id`**: `INSERT … ON CONFLICT DO NOTHING`
   на каждом тике расходует значение sequence для уже обработанных событий (в логах Docker:
   delivery 1 → 42 → 45). При 1000 заметок с напоминанием «за 1 день» — около 5.7 млн значений
   в сутки, `int4` исчерпается примерно за год.
3. **Нет изменения серии «с этой даты»** без изменения прошлых вхождений: есть только
   «это вхождение» и «вся серия» (последняя переписывает и прошлое).
4. При конфликте кнопка «Загрузить актуальную версию» **теряет локальные правки**.

### P1 — UX и адаптивность
5. Телефон: навигация в шапке разваливается в столбец и занимает треть экрана.
6. Телефон: месячная сетка нечитаема (обрывки вроде «0…»), перетаскивание на сенсорном экране
   не работает (HTML5 DnD), нет альтернативы.
7. Неделя на планшете: заголовки обрезаны до «За…».
8. Редактор на телефоне — уменьшенный десктопный диалог; мелкие чекбоксы; нет закреплённой
   панели действий.
9. Фильтры списка на телефоне занимают весь первый экран.
10. Нет визуальной системы: системные цвета/отступы без токенов, нет иконок, нет состояний
    наведения/фокуса, нет иерархии в карточках, нет превью текста.
11. Подтверждения через `window.confirm`, уведомления об успехе отсутствуют, ошибки сети
    показываются только текстом внутри форм; нет состояний загрузки (только «Загрузка…»)
    и ошибки сервера на страницах.
12. Диалог без ловушки фокуса и возврата фокуса; закрытие с несохранёнными правками без
    предупреждения.

### P2 — шлифовка
13. Пагинация без номера диапазона («1–20 из 51»).
14. Выбор цвета тега только через нативный color picker, без палитры.
15. Выбор часового пояса — длинный `select` из ~600 значений без поиска.

## План
1. Backend P0: обязательная версия во всех мутациях заметок/вхождений; не расходовать sequence;
   разделение серии «с этой даты»; тесты двух клиентов и одновременных запросов.
2. Визуальная система: токены, компоненты (кнопки, поля, переключатели, диалог, подтверждение,
   тосты, состояния), иконки (inline SVG), переработка экранов.
3. Адаптивность: боковая панель на десктопе, нижняя навигация + кнопка «создать» на телефоне,
   мобильный календарь (месяц с точками + повестка выбранного дня, повестка недели), диалоги
   на весь экран, фильтры в выдвижной панели.
4. UX: черновик при конфликте (перенос правок на актуальную версию), предупреждение о
   несохранённых правках, тосты после подтверждения сервера, состояния загрузки/ошибки.
5. Регрессия: тесты, e2e на ширинах 360–1440, два браузерных контекста, Docker rebuild на
   существующих данных, перезапуск.
