# Notetaker

Веб-приложение для заметок, привязанных к дате и времени: теги, календарь (месяц/неделя/день,
перетаскивание), повторяющиеся заметки с изменением отдельных вхождений, напоминания
(email + уведомления в браузере), поиск, фильтры, пагинация, экран «Предстоящие», корзина.

Разработано ИИ-агентом Claude Code (модель Claude Opus 5.5) — см. `docs/WORKLOG.md`.

## Возможности
- **Заметки:** заголовок, текст, дата/время, ≥1 тег, активность, даты создания/изменения;
  CRUD, переключение активности, корзина с восстановлением и окончательным удалением.
- **Теги:** создание, переименование, цвет, удаление (нельзя удалить единственный тег заметки).
- **Повторения:** ежедневно/еженедельно/ежемесячно с датой окончания; изменить, перенести или
  удалить одно вхождение, не трогая серию; «как в серии» возвращает вхождение.
- **Напоминания:** за 10 минут / 1 час / 1 день; email (SMTP или лог) и уведомление во всех
  открытых вкладках; каждое напоминание доставляется один раз; системное уведомление браузера —
  одно на все вкладки; политика для напоминаний, пропущенных во время простоя.
- **Календарь:** месяц, неделя, день; клик открывает заметку; перетаскивание переносит заметку
  (у серии — только вхождение, с проверкой правил серии).
- **Список:** серверный поиск по заголовку и тексту, фильтры по тегам, активности и периоду,
  сортировка по дате заметки или изменения, пагинация.
- **«Предстоящие»:** сегодня / эта неделя / прошедшие активные; заметка переезжает в
  «прошедшие» без перезагрузки.
- **Настройки:** email и часовой пояс; смена пояса меняет только отображение.
- **Синхронизация вкладок** по WebSocket: изменения данных и состояние уведомлений.

## Запуск через Docker Compose
```bash
docker compose up --build
```
- Приложение: http://localhost:8080
- Mailpit (письма-напоминания): http://localhost:8025

Миграции применяются автоматически при старте backend.

> В среде разработки Docker был недоступен (нет прав на `docker.sock`), поэтому
> `docker compose up` **не проверялся**; проверен только синтаксис (`docker compose config`).
> Всё остальное проверено на локальном PostgreSQL 16 (см. ниже и `docs/TESTING.md`).

## Локальный запуск без Docker
Нужны Python 3.12 и Node.js ≥ 20 (проверено на Node 26).

```bash
python3 -m venv .venv
.venv/bin/pip install -r backend/requirements-dev.txt pixeltable-pgserver
scripts/dev-db.sh start                     # PostgreSQL 16 на 127.0.0.1:5433

cd backend
../.venv/bin/alembic upgrade head
../.venv/bin/uvicorn app.main:app --port 8001 --reload

cd frontend                                 # в другом терминале
npm install
npm run dev                                 # http://localhost:5173 (проксирует /api и /ws на :8001)
```
`scripts/dev-db.sh` запускает настоящий PostgreSQL 16 из pip-пакета `pixeltable-pgserver`
(DECISIONS D2). Можно использовать свой PostgreSQL через `NOTETAKER_DATABASE_URL`.
По умолчанию письма пишутся в лог backend (`NOTETAKER_EMAIL_BACKEND=console`).

## Тесты
```bash
scripts/dev-db.sh start
cd backend && ../.venv/bin/pytest -q           # 71 тест на реальном PostgreSQL
cd frontend && npm test && npm run build       # vitest (17) + проверка типов и сборка
cd frontend && npm run e2e                     # Playwright (5 сценариев), сам поднимает backend и Vite
.venv/bin/python scripts/restart_check.py      # SIGKILL/рестарт реального процесса + SMTP-приёмник
```
Для e2e нужен Chromium: `npx playwright install chromium` (или путь в `PW_CHROMIUM`).

## Конфигурация
| Переменная | По умолчанию | Назначение |
|---|---|---|
| `NOTETAKER_DATABASE_URL` | `postgresql+psycopg://postgres@127.0.0.1:5433/notetaker` | БД |
| `NOTETAKER_EMAIL_BACKEND` | `console` | `console`, `smtp` или `memory` (тесты) |
| `NOTETAKER_SMTP_HOST` / `_PORT` / `_FROM` | `localhost` / `1025` / `notetaker@localhost` | SMTP |
| `NOTETAKER_SCHEDULER_INTERVAL_SECONDS` | `15` | Период планировщика напоминаний |
| `NOTETAKER_SCHEDULER_ENABLED` | `true` | Включить планировщик |
| `NOTETAKER_CORS_ORIGINS` | `["http://localhost:5173", …]` | CORS для dev-сервера |

Секретов в репозитории нет; пароль БД для compose задаётся через `.env` (пример — `.env.example`).

## Как это устроено (кратко)
- Все моменты хранятся в UTC (`timestamptz`); у заметки есть свой часовой пояс, в котором
  разворачивается серия (09:00 остаётся 09:00 при переходе на летнее время). Отображение — в
  поясе пользователя.
- Вхождения серий не хранятся, а вычисляются для окна; исключения — таблица
  `occurrence_overrides` с ключом `(note_id, original_start)`.
- Напоминания: планировщик внутри backend раз в 15 с ищет наступившие события и пишет их в
  `reminder_deliveries` с уникальным ключом события (`INSERT … ON CONFLICT DO NOTHING`, advisory
  lock); email отправляется из этой же таблицы с блокировкой строки (`FOR UPDATE SKIP LOCKED`).
  Подробности и обоснования — `docs/DECISIONS.md`.

## Известные ограничения
- `docker compose up` не проверен в среде разработки (нет доступа к Docker).
- Один экземпляр backend: WebSocket-рассылка работает в памяти процесса. Несколько экземпляров
  не создадут дублей напоминаний (advisory lock + уникальный ключ), но вкладки, подключённые к
  другому экземпляру, не получат событие сразу (нужен Postgres LISTEN/NOTIFY).
- Строгое «ровно один раз» для внешнего SMTP невозможно: если процесс упадёт после того, как
  SMTP принял письмо, но до фиксации статуса, письмо уйдёт повторно (с тем же Message-ID).
- Список и поиск работают на уровне серий: поиск — по полям серии (не по изменённым заголовкам
  отдельных вхождений), фильтр периода — по пересечению диапазона серии с периодом.
- «Прошедшие активные» показывают вхождения за последние 30 дней.
- Серия ограничена 5 годами; monthly на 29–31 число прижимается к концу месяца.
- Длительности у заметок нет (только момент), в виде «День» перенос меняет час.
- Интерфейс только на русском, неделя начинается с понедельника; вёрстка под мобильные — базовая.
- Без авторизации (по заданию): одно рабочее пространство на установку.
- Локальная сборка PostgreSQL без `pg_trgm`: поиск без trigram-индекса (в Docker-образе индекс
  создаётся). На 5000 заметках запрос списка ≤ 15 мс и без индекса.
